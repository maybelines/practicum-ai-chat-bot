# Echo Weaving

The Echo Weaving is a clone technique created by Eldor Doreth.

This weaving allows the user to create one or more copies of themselves. The user's Mavren is evenly divided between themselves and their clones: creating one clone will give it half the user's Mavren, creating two clones will give each a third of the user's Mavren, and so on. Depending on how much Mavren the user has and how many clones they make, this rapid depletion of their reserves can be dangerous. Because of this, usually only those of at least senior guardian-level can safely use the standard Echo Weaving.
